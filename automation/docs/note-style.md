# 메모 어투

`note`·`note_ko`에 한국어 메모를 쓸 때의 어투 지침이다. 사람이 직접 쓸 때도, 에이전트나 LLM에게 메모를 맡길 때도 이 파일을 그대로 준다. 메모에 무엇을 담을지는 [DESIGN.md 4.7절](DESIGN.md#47-메모note-작성)에 있고, 여기서는 어떻게 쓸지만 다룬다.

## 형식

- 개조식으로 쓴다. 명사나 `~함`·`~임`·`~음`으로 끝내고, `~다`·`~습니다`로 끝내지 않는다.
- 내용이 여럿이면 마침표로 끊는다. 쌍반점(`;`)으로 이어 붙이지 않는다.
- 괄호는 짧은 보충에만 쓴다. 중요한 내용을 괄호 안에 넣지 않고, 괄호 안에 다시 괄호를 넣지 않는다.
- 강조용 굵은 글씨와 따옴표, 문장 사이에 끼우는 대시(`—`), 이모지는 쓰지 않는다. 따옴표와 `「」`는 원문을 옮겨 적을 때만 쓴다.

## 표현

- 동사를 바로 쓴다. `진행`·`수행`·`실시`·`완료` 같은 말을 덧붙이지 않는다.
  - `대조를 진행함` → `대조함`
  - `일치 여부 확인 완료` → `일치함`
- 번역투를 피한다.
  - `~에 의해 등록됨` → `~가 등록함`
  - `~되어짐` → `~됨`
  - `~을 가지고 있음` → `~이 있음`
  - `~에 기반하여`, `~를 바탕으로` → `~로`, `~을 보고`
  - `~에 대한 확인` → `~ 확인`, `~에 있어서` → `~에서`
  - `~에서의`, `~으로의` → 문장을 풀어 쓴다
- `-성`·`-적`·`-화` 명사를 쌓지 않는다. `표기 일관성 확보` → `표기를 맞춤`, `공식적 근거` → `공식 근거`
- 내용 없는 꾸밈말은 지운다. `정확히`, `명확하게`, `최종적으로`, `면밀히` 같은 말
- 영어 병기는 처음 한 번만 한다. ISRC, BPM처럼 널리 쓰는 약어는 그대로 둔다.

## 손대지 않는 것

- 고유명사, 곡명·인명 원문, 수치, 날짜, URL, 옮겨 적은 원문
- 확신의 정도. `동일인은 미확인`, `~로 보임`을 단정으로 바꾸지 않고, 확인한 사실을 `~일 수 있음`으로 흐리지도 않는다.
- 검증기가 찾는 고정 문구 `공식 미게재`, `공식보다 최신`, `공식 계정`

## 다 쓰고 나서

이 저장소를 처음 보는 사람이 메모만 읽고 값이 왜 이렇게 됐는지 알 수 있는지 본다. 결정 번호나 절 번호를 찾아봐야 이해되는 메모라면 다시 쓴다.
