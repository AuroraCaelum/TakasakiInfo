## このDBについて

- ラブライブ！シリーズの楽曲、アルバム、メンバー、声優に関する多言語DBです。
- 各曲の日本語タイトル、ローマ字表記、韓国語訳と、発売日、YouTube Music のリンクを提供します。
  - リンクは正式にストリーミング配信されている曲に限ります。ない場合は `NA` です。
  - アルバムにストリーミング版がない場合は、別のアルバムに収録された同じ音源にリンクし、`Note`（備考）列に `Link is from the [アルバム]` と記します。
- エンティティファイルと SQLite DB には、音源ごとの長さ、キー、BPM、ムードのラベルもあります（[説明](#db-schema)）。キーと BPM のデータは [ReccoBeats](https://reccobeats.com) によるものです。

### 検索 API

読み取り専用で、自由に使えます。すべての応答は `{"data": …, "meta": {…}}` で、名前とタイトルは全言語で入ります。`?include=evidence` を付けると、値ごとの出典と状態も入ります。id はデータの id のままで（`muse/snow-halation`）、音源 id の `#` は `%23` で送ります。一覧は `limit`（最大100）と `cursor`（前のページの `meta.next`）で分けて受け取ります。

| エンドポイント | 内容 |
| :-- | :-- |
| `GET /api/v1/search?q=snow hal` | 名前が一致する曲、リリース、人物、キャラクター、アーティスト、ライブ、会場。日本語、ローマ字、韓国語、クレジットの別名で探せます。`type`、`project` で絞り込めます。 |

## DB スキーマ

エンティティファイルには DB 全体が入っています。CSV・JSON ファイルにないものもあります: リリースの形態（品番・メディア）、ディスク、YouTube Music のアルバム、公式ページとスマートリンク、値ごとの出典。

- エンティティの種類ごとに `{{CDN}}/data/v1/<ファイル>` が1つで、形は `{"schemaVersion": "1.0.0", "dbLastUpdate": "…", "count": n, "data": [ … ]}` です。
- エンティティ同士は id で参照します（`"artist": "ikizuraibu"`、`"recording": "ikizulive/homerun-queen#original"`）。id は一度決めたら変わりません。
- 日付は `YYYY-MM-DD` です。名前とタイトルは **Names** オブジェクトで、値のない言語は省きます。
- **既定値**: *必須* のフィールドは常にあり、*—* のフィールドは不明なら省き、それ以外は値が保存されていないとき表の値が入ります。
- 同じフィールドを同じ説明付きで JSON Schema としても出します: `schema/<ファイル>`。DB の元になる [`data/`](data) の YAML ファイルもフィールドは同じで、既定値は書きません。
- フィールドの説明は英語です。

## CSV の構造

- 各ファイルの最初の行はヘッダーです。
- 値は `,` で区切り、1つの列に複数の値がある場合は `;` で区切ります。

  | **21** | | | | | | |
  | 発音(かな) | | | | | | |

- メンバーデータ (`members/<グループ>.csv`):

  | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
  | :-: | :-: | :-: | :-: | :-: | :-: | :-: | :-: | :-: |
  | 名前(日本語) | 名前(ローマ字) | 名前(韓国語) | 声優(日本語) | 声優(ローマ字) | 声優(韓国語) | 所属ユニット | 誕生日 | 声優の誕生日 |

  卒業したメンバーも含みます。ユニットが回ごとに変わるグループは `所属ユニット` が空です。
  キャラクターの誕生日は `MM-DD`、声優の誕生日は `YYYY-MM-DD`（生年非公表なら `MM-DD`）です。声優が2人の役は名前の順に誕生日を並べ、見つからなかった誕生日は空欄です。
- 行の順序: 曲は発売日順、メンバーと声優は公式サイトのメンバー順です。

## JSON の構造

- **曲** (`songs/<グループ>/<グループ>.json`): トラックごとに1つのオブジェクトです。Off Vocal と Drama Part は含みません。複数人のクレジットは配列です。
- **アルバム** (`albums/<グループ>/<グループ>.json`): アルバムと収録曲です。
- **全体** (`TakasakiInfo.json`): `{"dbLastUpdate", "data"}`。全グループのトラックを1回ずつ発売日順に、`category` 付きで収めます。
- **ライブ** (`concerts/<グループ>/<グループ>.json`): ツアーと公演地、会場、セットリストです。`::` で始まる項目は曲ではなく目印です（`::MC1`、`::VID1`、`::Encore`）。
- **エンティティファイル** (`/data/v1/`、[ダウンロードと API](#downloads-and-api) を参照): エンティティごとに JSON ファイル1つです。上記のファイルにない形態（品番・メディア）、ディスク、YouTube Music のアルバム、公式ページ・スマートリンク、出典まで収めます。全フィールドの説明は [DB スキーマ](#db-schema) にあります。
