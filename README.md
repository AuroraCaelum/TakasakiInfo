## v1 schema

The v1 files hold the whole database, with what the CSV and JSON files leave out: each release's editions with catalog numbers and media, its discs, YouTube Music albums, official page and smart link, and the source of every value.

- One file per entity type at `https://d1zzovwupaegwb.cloudfront.net/data/v1/<file>`, each as `{"schemaVersion": "1.0.0", "dbLastUpdate": "…", "count": n, "data": [ … ]}`.
- Entities refer to each other by id (`"artist": "ikizuraibu"`, `"recording": "ikizulive/homerun-queen#original"`). An id does not change once made.
- Dates are `YYYY-MM-DD`. Names and titles are **Names** objects; a language without a value is left out.
- **Default**: *required* fields are always there, fields marked *—* are left out when not known, and the others hold the value shown when nothing is stored.
- The same fields as JSON Schema, with these descriptions: `schema/<file>`. The YAML files in [`data/`](data) that the database is built from have the same fields and leave out defaults.

| `note` | string | — | Why this source, or what differs from other sources (often in Korean). |

## English

### About

- A multilingual database of terms from the Love Live! series: songs, albums, members and voice actors.
- Each song comes with its Japanese title, romanization and Korean translation, its release date and a YouTube Music link.
  - A link is given only when the song is officially on streaming; otherwise the value is `NA`.
  - When an album has no streaming release of its own, the link points to the same recording on another album, and the `Note` column says `Link is from the [album]`.

### Before you start

- Official sites are always checked first. What they do not publish (Korean names and titles, concert setlists, readings) comes from community sources such as Love Live! Fandom and Namuwiki, checked against each other.
- The data began as the hand-made lists of this repository (2023–2024). Every value taken from them has since been traced to a source, which the v1 files give with each value; the few that disagree with their sources are under review.
- Names whose official form is English have no Korean translation.
- **The data is still being configured: some entries may be missing and the structure may change.**
- Each file is named after its group:
  - μ’s → `Muse`
  - Aqours → `Aqours`
  - Nijigasaki High School Idol Club → `Nijigaku`
  - Liella! → `Liella`
  - Hasunosora Girls' High School Idol Club → `Hasunosora`
  - School Idol Musical → `Musical`
  - Ikizulive! LOVELIVE! BLUEBIRD → `Ikizulive`
  - Yohane the Parhelion → `Yohane`
- `Category` values: `Muse`, `Aqours`, `Nijigaku`, `Liella`, `Hasunosora`, `Musical`, `Ikizulive`, `Yohane`, `Others` (`Others` is for cross-project units and collaborations).

### CSV structure

- The first row of each file is a header.
- Values are separated by `,`. When a column holds several values, they are separated by `;`.
- Album data (`albums/<Group>/<Group>.csv`):

  | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
  | :-: | :-: | :-: | :-: | :-: | :-: | :-: |
  | Album | Track number | Title (ja) | Title (rom) | Title (ko) | Singer (ja) | Singer (rom) |
  | **7** | **8** | **9** | **10** | **11** | **12** | **13** |
  | Singer (ko) | Lyricist (ja) | Lyricist (rom) | Lyricist (ko) | Composer (ja) | Composer (rom) | Composer (ko) |
  | **14** | **15** | **16** | **17** | **18** | **19** | **20** |
  | Arranger (ja) | Arranger (rom) | Arranger (ko) | Release date | YouTube link | Category | Note |
  | **21** | | | | | | |
  | Pronunciation (kana) | | | | | | |

- Member data (`members/<Group>.csv`):

  | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
  | :-: | :-: | :-: | :-: | :-: | :-: | :-: |
  | Name (ja) | Name (rom) | Name (ko) | Voice actor (ja) | Voice actor (rom) | Voice actor (ko) | Unit |

  Graduated members are included. `Unit` is empty for groups whose units change from round to round.
- Row order: songs by release date; members and voice actors in the order of the official site.

### JSON structure

- **Songs** (`songs/<Group>/<Group>.json`): one object per track, without Off Vocal and Drama Part tracks. A credit shared by several people is an array.
- **Albums** (`albums/<Group>/<Group>.json`): each album with its tracks.
- **Every group** (`TakasakiInfo.json`): `{"dbLastUpdate", "data"}` with every track of every group once, by release date, with its `category`.
- **Concerts** (`concerts/<Group>/<Group>.json`): tours with their stops, venues and setlists. Setlist entries starting with `::` are markers, not songs (`::MC1`, `::VID1`, `::Encore`).
- **v1 files** (`/data/v1/`, see [Downloads and API](#downloads-and-api)): one JSON file per entity, including what the files above leave out: editions with catalog numbers and media, discs, YouTube Music albums, official pages and smart links, sources. Every field is described in [v1 schema](#v1-schema).

## 한국어

### 소개

- 러브 라이브! 시리즈의 노래, 앨범, 멤버, 성우에 관한 다국어 DB입니다.
- 곡마다 일본어 제목, 로마자 표기, 한국어 번역과 발매일, YouTube Music 링크를 제공합니다.
  - 링크는 정식으로 스트리밍에 공개된 곡에만 있고, 없으면 `NA`입니다.
  - 앨범에 스트리밍판이 따로 없으면 다른 앨범에 실린 같은 음원으로 링크하고, `비고` 열에 `Link is from the [앨범]`이라고 적습니다.

### 시작하기 전에

- 항상 공식 사이트를 먼저 확인합니다. 공식에 없는 정보(한국어 이름·제목, 공연 세트리스트, 읽기 등)는 Love Live! Fandom, 나무위키 같은 커뮤니티 자료에서 가져와 서로 대조합니다.
- 이 데이터는 이 저장소의 수작업 목록(2023~2024)에서 시작했습니다. 그 값은 모두 출처를 다시 찾았고, v1 파일에는 값마다 출처가 함께 실립니다. 출처와 다른 몇몇 값은 검토 중입니다.
- 공식 명칭이 영어이면 한국어 번역을 넣지 않습니다.
- **아직 데이터를 구성하는 중이라 빠진 항목이 있을 수 있고, 구조가 바뀔 수 있습니다.**
- 파일 이름은 그룹의 영문 이름입니다.
  - μ’s → `Muse`
  - Aqours → `Aqours`
  - 니지가사키 학원 스쿨 아이돌 동호회 → `Nijigaku`
  - Liella! → `Liella`
  - 하스노소라 여학원 스쿨 아이돌 클럽 → `Hasunosora`
  - 스쿨 아이돌 뮤지컬 → `Musical`
  - 이키즈라이부! LOVELIVE! BLUEBIRD → `Ikizulive`
  - 환일의 요하네 → `Yohane`
- `카테고리` 값: `Muse`, `Aqours`, `Nijigaku`, `Liella`, `Hasunosora`, `Musical`, `Ikizulive`, `Yohane`, `Others` (`Others`는 여러 프로젝트에 걸친 유닛과 콜라보)

### CSV 구조

- 각 파일의 첫 행은 헤더입니다.
- 값은 `,`로 구분하고, 한 열에 여러 값이 들어가면 `;`로 구분합니다.
- 음반 데이터 (`albums/<그룹>/<그룹>.csv`): `앨범명`, `트랙 번호`, `제목(일본어)`, `제목(로마자)`, `제목(한국어)`, `가수(일본어)`, `가수(로마자)`, `가수(한국어)`, `작사(일본어)`, `작사(로마자)`, `작사(한국어)`, `작곡(일본어)`, `작곡(로마자)`, `작곡(한국어)`, `편곡(일본어)`, `편곡(로마자)`, `편곡(한국어)`, `발매일`, `유튜브 링크`, `카테고리`, `비고`, `발음(가나)`
- 멤버 데이터 (`members/<그룹>.csv`): `이름(일본어)`, `이름(로마자)`, `이름(한국어)`, `성우(일본어)`, `성우(로마자)`, `성우(한국어)`, `소속 유닛`. 졸업 멤버도 들어 있고, 유닛이 회차마다 바뀌는 그룹은 `소속 유닛`이 비어 있습니다.
- 행 순서: 곡은 발매일순, 멤버와 성우는 공식 홈페이지의 멤버 순서입니다.

### JSON 구조

- **곡** (`songs/<그룹>/<그룹>.json`): 트랙마다 객체 하나입니다. Off Vocal과 Drama Part는 빠집니다. 여러 사람이 맡은 크레딧은 배열입니다.
- **음반** (`albums/<그룹>/<그룹>.json`): 앨범과 수록곡입니다.
- **전체** (`TakasakiInfo.json`): `{"dbLastUpdate", "data"}`. 모든 그룹의 트랙을 한 번씩 발매일순으로, `category`와 함께 담습니다.
- **공연** (`concerts/<그룹>/<그룹>.json`): 투어와 공연지, 회장, 세트리스트입니다. `::`로 시작하는 항목은 곡이 아니라 표식입니다(`::MC1`, `::VID1`, `::Encore`).
- **v1 파일** (`/data/v1/`, [Downloads and API](#downloads-and-api) 참고): 엔티티마다 JSON 파일 하나입니다. 위 파일에 없는 에디션(품번·매체), 디스크, YouTube Music 앨범, 공식 페이지·스마트링크, 출처까지 담습니다. 모든 필드의 설명은 [v1 schema](#v1-schema)에 있습니다.
- 예시는 [English](#english)의 JSON structure를 참고하세요.

## 日本語

### このDBについて

- ラブライブ！シリーズの楽曲、アルバム、メンバー、声優に関する多言語DBです。
- 各曲の日本語タイトル、ローマ字表記、韓国語訳と、発売日、YouTube Music のリンクを提供します。
  - リンクは正式にストリーミング配信されている曲に限ります。ない場合は `NA` です。
  - アルバムにストリーミング版がない場合は、別のアルバムに収録された同じ音源にリンクし、`Note`（備考）列に `Link is from the [アルバム]` と記します。

### はじめに

- 常に公式サイトを最初に確認します。公式にない情報（韓国語の名前・タイトル、ライブのセットリスト、読みなど）は Love Live! Fandom やナムウィキなどのコミュニティ資料から取り、相互に照合します。
- このデータは本リポジトリの手作業のリスト（2023〜2024年）から始まりました。その値はすべて出典を確認し直しており、v1 ファイルには値ごとに出典を載せています。出典と食い違う一部の値は確認中です。
- 公式名称が英語の場合、韓国語訳は含みません。
- **データはまだ構成中のため、欠けている項目があったり、構造が変わったりすることがあります。**
- 各ファイルの名前は、グループの英語名です。
  - μ’s → `Muse`
  - Aqours → `Aqours`
  - 虹ヶ咲学園スクールアイドル同好会 → `Nijigaku`
  - Liella! → `Liella`
  - 蓮ノ空女学院スクールアイドルクラブ → `Hasunosora`
  - スクールアイドルミュージカル → `Musical`
  - イキヅライブ！ LOVELIVE! BLUEBIRD → `Ikizulive`
  - 幻日のヨハネ → `Yohane`
- `Category`（分類）の値: `Muse`, `Aqours`, `Nijigaku`, `Liella`, `Hasunosora`, `Musical`, `Ikizulive`, `Yohane`, `Others`（`Others` はプロジェクトをまたぐユニットとコラボ）

### CSV の構造

- 各ファイルの最初の行はヘッダーです。
- 値は `,` で区切り、1つの列に複数の値がある場合は `;` で区切ります。
- アルバムデータ (`albums/<グループ>/<グループ>.csv`): `アルバム名`, `トラック`, `タイトル(日本語)`, `タイトル(ローマ字)`, `タイトル(韓国語)`, `歌手(日本語)`, `歌手(ローマ字)`, `歌手(韓国語)`, `作詞(日本語)`, `作詞(ローマ字)`, `作詞(韓国語)`, `作曲(日本語)`, `作曲(ローマ字)`, `作曲(韓国語)`, `編曲(日本語)`, `編曲(ローマ字)`, `編曲(韓国語)`, `発売日`, `YouTubeリンク`, `分類`, `備考`, `発音(かな)`
- メンバーデータ (`members/<グループ>.csv`): `名前(日本語)`, `名前(ローマ字)`, `名前(韓国語)`, `声優(日本語)`, `声優(ローマ字)`, `声優(韓国語)`, `所属ユニット`。卒業したメンバーも含みます。ユニットが回ごとに変わるグループは `所属ユニット` が空です。
- 行の順序: 曲は発売日順、メンバーと声優は公式サイトのメンバー順です。

### JSON の構造

- **曲** (`songs/<グループ>/<グループ>.json`): トラックごとに1つのオブジェクトです。Off Vocal と Drama Part は含みません。複数人のクレジットは配列です。
- **アルバム** (`albums/<グループ>/<グループ>.json`): アルバムと収録曲です。
- **全体** (`TakasakiInfo.json`): `{"dbLastUpdate", "data"}`。全グループのトラックを1回ずつ発売日順に、`category` 付きで収めます。
- **ライブ** (`concerts/<グループ>/<グループ>.json`): ツアーと公演地、会場、セットリストです。`::` で始まる項目は曲ではなく目印です（`::MC1`, `::VID1`, `::Encore`）。
- **v1 ファイル** (`/data/v1/`、[Downloads and API](#downloads-and-api) を参照): エンティティごとに JSON ファイル1つです。上記のファイルにない形態（品番・メディア）、ディスク、YouTube Music のアルバム、公式ページ・スマートリンク、出典まで収めます。全フィールドの説明は [v1 schema](#v1-schema) にあります。
- 例は [English](#english) の JSON structure をご覧ください。
