## DB 스키마

엔티티 파일에는 DB 전체가 들어 있습니다. CSV·JSON 파일에 없는 것도 있습니다: 발매물의 에디션(품번·매체), 디스크, YouTube Music 앨범, 공식 페이지와 스마트링크, 값마다의 출처.

- 엔티티 종류마다 `https://d1zzovwupaegwb.cloudfront.net/data/v1/<파일>` 하나이고, 형태는 `{"schemaVersion": "1.0.0", "dbLastUpdate": "…", "count": n, "data": [ … ]}`입니다.
- 엔티티끼리는 id로 가리킵니다(`"artist": "ikizuraibu"`, `"recording": "ikizulive/homerun-queen#original"`). id는 한 번 정하면 바뀌지 않습니다.
- 날짜는 `YYYY-MM-DD`입니다. 이름과 제목은 **Names** 객체이고, 값이 없는 언어는 빠집니다.
- **기본값**: *필수* 필드는 항상 있고, *—* 필드는 모르면 빠지며, 나머지는 저장된 값이 없을 때 표의 값이 들어갑니다.
- 같은 필드를 같은 설명과 함께 JSON Schema로도 냅니다: `schema/<파일>`. DB를 만드는 [`data/`](data)의 YAML 파일도 필드가 같고, 기본값은 적지 않습니다.
- 필드 설명은 영어입니다.

- `duration`: 레이블이 음원을 배포할 때 붙인 길이. YouTube Music, Apple Music, Deezer에서 가져옵니다.

| `slow` | スロー | Slow | 느린 | `bpm` 100 미만 |
| `bright` | 明るい | Bright | 밝은 | 장조 |

## 시작하기 전에

- 항상 공식 사이트를 먼저 확인합니다. 공식에 없는 정보(한국어 이름·제목, 공연 세트리스트, 읽기 등)는 Love Live! Fandom, 나무위키 같은 커뮤니티 자료에서 가져와 서로 대조합니다.
- 이 데이터는 이 저장소의 수작업 목록(2023~2024)에서 시작했습니다. 그 값은 모두 출처를 다시 찾았고, 엔티티 파일에는 값마다 출처가 함께 실립니다. 출처와 다른 몇몇 값은 검토 중입니다.
- 공식 명칭이 영어이면 한국어 번역을 넣지 않습니다.
- **아직 데이터를 구성하는 중이라 빠진 항목이 있을 수 있고, 구조가 바뀔 수 있습니다.**
- 파일 이름은 그룹의 영문 이름입니다.
  - μ’s → `Muse`
  - Aqours → `Aqours`
  - 니지가사키 학원 스쿨 아이돌 동호회 → `Nijigaku`
  - Liella! → `Liella`
  - 하스노소라 여학원 스쿨 아이돌 클럽 → `Hasunosora`
  - 스쿨 아이돌 뮤지컬 → `Musical`
  - 이키즈라이브! LOVELIVE! BLUEBIRD → `Ikizulive`
  - 환일의 요하네 → `Yohane`
- `카테고리` 값: `Muse`, `Aqours`, `Nijigaku`, `Liella`, `Hasunosora`, `Musical`, `Ikizulive`, `Yohane`, `Others` (`Others`는 여러 프로젝트에 걸친 유닛과 콜라보)

## CSV 구조

- 각 파일의 첫 행은 헤더입니다.
- 값은 `,`로 구분하고, 한 열에 여러 값이 들어가면 `;`로 구분합니다.
- 음반 데이터 (`albums/<그룹>/<그룹>.csv`):

  | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
  | :-: | :-: | :-: | :-: | :-: | :-: | :-: |
  | 앨범명 | 트랙 번호 | 제목(일본어) | 제목(로마자) | 제목(한국어) | 가수(일본어) | 가수(로마자) |
  | **7** | **8** | **9** | **10** | **11** | **12** | **13** |
  | 가수(한국어) | 작사(일본어) | 작사(로마자) | 작사(한국어) | 작곡(일본어) | 작곡(로마자) | 작곡(한국어) |
  | **14** | **15** | **16** | **17** | **18** | **19** | **20** |
  | 편곡(일본어) | 편곡(로마자) | 편곡(한국어) | 발매일 | 유튜브 링크 | 카테고리 | 비고 |
  | **21** | | | | | | |
  | 발음(가나) | | | | | | |

- 멤버 데이터 (`members/<그룹>.csv`):

  | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
  | :-: | :-: | :-: | :-: | :-: | :-: | :-: | :-: | :-: |
  | 이름(일본어) | 이름(로마자) | 이름(한국어) | 성우(일본어) | 성우(로마자) | 성우(한국어) | 소속 유닛 | 생일 | 성우 생일 |

  졸업 멤버도 들어 있습니다. 유닛이 회차마다 바뀌는 그룹은 `소속 유닛`이 비어 있습니다.
  캐릭터 생일은 `MM-DD`, 성우 생일은 `YYYY-MM-DD`(생년 비공개면 `MM-DD`)입니다. 성우가 둘인 배역은 이름 순서대로 생일을 적고, 찾지 못한 생일은 비워 둡니다.
- 행 순서: 곡은 발매일순, 멤버와 성우는 공식 홈페이지의 멤버 순서입니다.

## JSON 구조

- **곡** (`songs/<그룹>/<그룹>.json`): 트랙마다 객체 하나입니다. Off Vocal과 Drama Part는 빠집니다. 여러 사람이 맡은 크레딧은 배열입니다.
- **음반** (`albums/<그룹>/<그룹>.json`): 앨범과 수록곡입니다.
- **전체** (`TakasakiInfo.json`): `{"dbLastUpdate", "data"}`. 모든 그룹의 트랙을 한 번씩 발매일순으로, `category`와 함께 담습니다.
- **공연** (`concerts/<그룹>/<그룹>.json`): 투어와 공연지, 회장, 세트리스트입니다. `::`로 시작하는 항목은 곡이 아니라 표식입니다(`::MC1`, `::VID1`, `::Encore`).
- **엔티티 파일** (`/data/v1/`, [내려받기와 API](#downloads-and-api) 참고): 엔티티마다 JSON 파일 하나입니다. 위 파일에 없는 에디션(품번·매체), 디스크, YouTube Music 앨범, 공식 페이지·스마트링크, 출처까지 담습니다. 모든 필드의 설명은 [DB 스키마](#db-schema)에 있습니다.
